# Wickly 📈🕯️ (Single-Developer Project)

**AI-Powered Candlestick Pattern Recognition & Real-Time Stream Analysis**

**Live Demo:** [Wickly Web Platform](https://wickly-production.up.railway.app/flask/)

**Developer:** Muhammad Talha

---

## Inspiration 💡
Technical analysis is a cornerstone of trading, yet manually identifying patterns across hundreds of charts is time-consuming and prone to human error. I wanted to see if I could automate the "eyes" of a trader using computer vision.

## What It Does 🤔
Wickly is a high-performance web application that uses a custom-trained Convolutional Neural Network (CNN) to analyze trading charts.
* **Accepts Image Uploads:** Users can upload snippets of financial charts.
* **Identifies 30+ Patterns:** Recognizes complex formations like "Morning Star" and "Hammer."
* **Real-Time Live Stream:** Monitors live market data streams to identify patterns as they form.

## Tech Stack 🛠️
* **Languages:** Python, JavaScript, HTML/CSS, SQLite
* **ML Frameworks:** Fastai, NumPy, Pandas
* **Backend:** FastAPI, Flask
* **Deployment:** Railway, Render, Docker
